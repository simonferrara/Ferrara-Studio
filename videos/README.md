# Showreel videos

The homepage hero plays these clips in order. Any missing file falls back to an animated color field, so the site works before every clip exists.

| File | Title on screen | Color |
|---|---|---|
| `01-websites.mp4` | WEBSITES | lime |
| `02-7days.mp4` | IN 7 DAYS | gold |
| `03-landing-pages.mp4` | LANDING PAGES | electric blue |
| `04-more-clients.mp4` | MORE CLIENTS | red |
| `05-ecommerce.mp4` | E-COMMERCE | blush pink |
| `06-seo.mp4` | SEO | white / silver |
| `07-branding.mp4` | BRANDING | orange |
| `08-mobile-first.mp4` | MOBILE FIRST | purple |
| `09-speed.mp4` | SPEED | cyan |
| `10-ferrara-studio.mp4` | LET'S BUILD | black + lime |

Optional vertical (9:16) versions for phones use the same name with `-vertical`, e.g. `01-websites-vertical.mp4`.

Specs: MP4 (H.264), 16:9, 1080p, 5–10 s, no audio, under ~3 MB each. Titles and colors are set in the `CLIPS` array in `index.html`.
